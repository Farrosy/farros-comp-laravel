# Farros Comp - E-Commerce Laptop Second

Aplikasi web e-commerce berbasis Laravel 11 untuk penjualan laptop second berkualitas, dilengkapi panel inventaris admin dan pembayaran Midtrans Sandbox.

## 🌐 Live Demo & Deployment
- **Web App:** [https://farros-comp.wasmer.app/](https://farros-comp.wasmer.app/)
- **Database:** TiDB Cloud Serverless (MySQL Compatible with SSL)

## 🛠️ Tech Stack
- **Backend:** Laravel 11, PHP 8.3, FrankenPHP
- **Database:** TiDB Cloud (Serverless MySQL)
- **Frontend:** Laravel Blade, Bootstrap 5, Bootstrap Icons
- **Integrasi:** Midtrans Snap (Sandbox), WhatsApp Business API Link
- **Deployment Platform:** Wasmer Edge Container

## ⚙️ Fitur Utama
- Autentikasi mandiri & Role-Based Access Control (Admin & Customer)
- Manajemen inventaris laptop (CRUD) dengan AJAX Quick Category & Masking Rupiah
- Katalog produk interaktif (Search, Filter Kategori, Sorting Spesifikasi & Harga)
- Checkout & Gateway Pembayaran Terintegrasi (Midtrans Sandbox & Webhook Callback)
- Edukasi kondisi unit (Grading Grade A+/A/B & SOP Garansi Toko)
